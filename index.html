nimbleUI
Design system

Small, calm, colour-only theming.

Made to cater the nimble suite of productivity apps by Monco.io. One structure, five accents; dark and light differ only in colour. Plain CSS and a little vanilla JS: no framework, no build step.

Get started View on GitHub

Why nimbleUI

A small kit that keeps a family of products consistent, and is easy to adopt in yours.

Colour-only themes

Dark and light change nothing but colour, so switching theme never moves the layout. A script checks it on every change.

Nothing to install

Two stylesheets and two scripts. No framework, no bundler, no dependencies: copy the files and go.

Behaviour from attributes

Drag and sort, inline edit, dialogs, menus, tabs and toasts, declared in HTML and working with mouse, touch and keyboard.

One accent per product

Emerald, rose, indigo, amber or violet with one attribute, or add your own as five colours per theme.

Safe and strict-CSP friendly

No inline scripts or styles required. User text is always text, never HTML.

Made for real content

Checked at 375px with no horizontal scroll; long names and URLs wrap instead of breaking the page.

Get started

Copy tokens.css, components.css, theme.js and behaviors.js from src/ into your project, then:

<html lang="en" data-theme="dark" data-accent="indigo">
<head>
  <script src="nimble/theme.js"></script>
  <link rel="stylesheet" href="nimble/tokens.css">
  <link rel="stylesheet" href="nimble/components.css">
</head>
<body>
  <button class="btn btn--primary">New</button>
  <script src="nimble/behaviors.js"></script>
</body>

Everything below is the reference markup: view the source of this page. Not a fit for apps that need a large component catalogue (data grids, date pickers, rich text).
